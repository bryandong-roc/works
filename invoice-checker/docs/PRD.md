# 產品規格（簡易版）

## 目標與範圍
提供可信、可驗證的紙本統一發票對獎工具：自動取得財政部號碼，累計當期中獎金額。
範圍外：雲端發票專屬獎對獎、帳號系統、伺服器端儲存。

## 功能需求
| 編號 | 需求 | 驗收標準 |
|---|---|---|
| FR1 | 自動抓取 | 腳本取得近 4 期官方頁面並解析；通過驗證才合併寫入 |
| FR2 | 資料驗證 | 特別獎/特獎 8 碼、頭獎 3 組 8 碼、頁面期別與領獎期間與計算值一致，否則拒絕 |
| FR3 | 對獎引擎 | 同張取最高獎；支援歷史期別的增開六獎 |
| FR4 | 輸入處理 | 全形轉半形、容許字軌；僅 8 碼才判定 |
| FR5 | 當期累計 | 顯示張數、中獎張數、金額合計；各期獨立；由號碼重算 |
| FR6 | 稅後預估 | 可開關；標示為估算 |
| FR7 | 領獎期限 | 顯示起訖；逾期警示 |
| FR8 | 資料透明 | 顯示來源、抓取時間、免責聲明；資料落後時警示 |

## 規則
特別獎1,000萬、特獎200萬、頭獎20萬；二至六獎為頭獎末7至3碼，4萬/1萬/4千/1千/2百。
中三獎(含)以上扣繳20%；中五獎(含)以上0.4%印花稅（設定領獎帳戶者免繳）。
領獎期間：起始月+3個月的6日至起始月+6個月的5日。

## 架構
排程腳本 → `data/draws.json` → 純靜態前端（`src/engine.js` 無 DOM 依賴，可單獨測試）。

## 待確認
