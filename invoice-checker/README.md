# 統一發票對獎（invoice-checker）

輸入紙本實體發票號碼，自動比對財政部公告的中獎號碼，並累計當期中獎金額。

## 功能
- 號碼來自財政部稅務入口網各期頁面，由腳本抓取並**驗證**後才寫入 `data/draws.json`
- 末 3 碼即時提示；輸入 8 碼自動判定最高獎別（含跨頭獎組取最高）
- 當期累計：已對張數、中獎張數、中獎金額合計；可開啟稅後預估（估算值）
- 顯示領獎期限，逾期與資料落後時主動警示
- 紀錄僅存於瀏覽器本機（localStorage），不上傳

## 使用
```bash
cd invoice-checker
npm test            # 對獎引擎與解析器測試（Node 18+，無外部套件）
npm run update      # 手動抓取最新號碼
npm run serve       # 本機預覽 http://localhost:8080
```

## 自動更新（可選）
GitHub 只會執行 repo 根目錄 `.github/workflows/` 內的 workflow，無法放在作品子資料夾。
需要排程時，將 `ci/update-draws.yml` 複製過去即可（路徑已限定在本資料夾內，不影響其他作品）。
不啟用也能運作：開獎後自行執行 `npm run update` 並提交 `data/draws.json`。

## 資料與限制
- 資料來源：財政部稅務入口網「統一發票中獎號碼」頁面。使用條款與 robots 規範尚待您確認。
- 解析器依頁面文字結構判斷；版型改變時驗證會失敗並保留舊資料，不會寫入錯誤號碼。
- **首次部署請先執行 `npm run update` 實測**：本專案的解析測試使用依官方號碼單文字結構建立的資料，並非即時抓取的原始 HTML。
- `data/draws.json` 內標示 `seed-manual` 的期別為人工建立，第一次成功抓取後會被官方頁面資料取代。
- 不含雲端發票專屬獎對獎（需載具歸戶，請用財政部平台或兌獎 APP）。
- 稅後預估僅供參考，實際以發獎單位扣繳為準。
